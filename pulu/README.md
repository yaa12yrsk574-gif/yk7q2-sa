# プルプルの島 — 全体体験の試作（2026-11-16）

【試遊URL】 https://yaa12yrsk574-gif.github.io/yk7q2-sa/pulu/
【引き継ぎ】 CLAUDE_HANDOFF.md を最初に読む。

本編の工房・狩り場を変更せず、別フォルダ pulu/ に作った3Dの一周体験。
「漂着したプルプルとの出会い → 生き物に憧れる → 工房で身体を作る → 指で姿勢コマを操り崖へ → デカブツと相撲 → また自由に遊ぶ」が繋がる。

操作：
・左パッドで移動。右の縦パッドで姿勢コマを動かす。下（しゃがむ）で保持して溜める→上（伸びる）へ素早く弾くと跳躍。
・PCではWASDで移動、上下矢印で姿勢コマ、Eで調べる。
・工房で関節なし／二脚、サイズ、弾力、しゃがみ、伸び、脚長、色、羽飾りを調整。
・カニと鳥を見に行く。崖の上の相撲場では同じ跳躍操作で体当たり練習。
・数値と観察状態は別キー pulu-island-slice-v1 の localStorage に保存。本編の保存領域とは分離。

構成：
index.html = UI、style.css = 外観
world.js = 3D島・生き物・建築・アバター
controls.js = iPad/PC操作
app.js = 物理・体験の進行・工房設定
CLAUDE_HANDOFF.md = 引き継ぎ用の判断・未実装事項

この段階は「造形・アニメを自由に作れる完成版」ではない。造形はスライダーのみ、コマも固定の2端点、関節物理・IK・アニメ編集・泳ぐ・羽ばたく等は未実装。
現時点ではGitHubの配置／ブラウザ配信の確認を優先。iPad実機操作はユーザーの確認が必要。
